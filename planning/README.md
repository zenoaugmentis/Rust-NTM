# Планирование Rust-NTM

[backlog.json](backlog.json) содержит стабильные ID, зависимости и критерии приёмки. [backlog.csv](backlog.csv) повторяет задачи в том же порядке. При изменении плана обновляйте критерий в JSON, CSV и соответствующей GitHub Issue.

[D01–D31 и этапы M10–M15](../docs/TEAM_ROADMAP.md) относятся к самостоятельной реализации 1.7.10. В GitHub этап представлен родительской карточкой с перечнем задач. В описании задачи указаны этап и зависимости. История первоначального плана доступна в [снимке репозитория](https://github.com/zenoaugmentis/Rust-NTM/tree/d833b92b8e8cbb48f2b229dd0b3d210a3527a0ea/planning).

Для локального просмотра используйте `python scripts/seed_github_issues.py --all` или выберите этап через `--milestones M11`. Опция `--apply` предназначена для публикации недостающих карточек через GitHub CLI; существующие стабильные ID распознаются по заголовкам. Список этапов и задач для обычной работы уже опубликован.
