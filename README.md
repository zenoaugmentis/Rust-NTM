# Ferrite Worlds

Ferrite Worlds — независимый проект по созданию клиента и сервера на Rust, совместимых с Minecraft Java Edition 1.7.10. Мы выбрали эту версию ради технических модов, с которыми в неё до сих пор хочется играть. Наша цель — сохранить знакомые миры и механики 1.7.10 и создать движок, рассчитанный на многопроцессорную обработку игрового мира.

## Во что мы хотим играть

Нас интересует мир, в котором можно построить производственную линию HBM’s Nuclear Tech Mod, написать на Lua программу для компьютера OpenComputers и управлять техникой MCHeli. Для каждого из этих модов мы планируем собственную нативную реализацию. Начнём с одной рабочей производственной цепочки, одного программируемого компьютера и одного летательного аппарата.

Для дальнейшего развития модов у движка будет собственный API. Через него можно будет добавлять блоки, предметы, машины и транспорт, сохранять их состояние в мире и синхронизировать его между игроками. Оригинальные версии модов под Forge служат эталоном игрового поведения.

## Что должно остаться совместимым

Сервер должен принимать обычный клиент Minecraft 1.7.10 по протоколу 5 и работать с существующими мирами этой версии. Собственный клиент также должен уметь подключаться к ванильному серверу. Это позволит проверять и развивать обе стороны независимо.

Совместимость касается и самой игры. Если в сохранении лежит сундук с предметами, после открытия мира должны сохраниться его содержимое и свойства предметов. Если игрок собрал схему из повторителей и ламп, порядок её переключений должен соответствовать 1.7.10. Именно для таких случаев мы сверяем работу движка с оригинальной игрой.

## Как будет работать движок

Для сервера важна стабильность игрового тика, особенно когда несколько игроков одновременно исследуют мир. Чтение и подготовку чанков планируем выполнять в фоновых потоках. Готовые данные сервер будет вводить в симуляцию в определённом порядке, чтобы скорость диска не меняла результат работы механизмов.

Один из наших критериев прост: если игрок добежал до области, которую сервер ещё загружает, он не должен провалиться сквозь землю. Сервер должен удержать последнюю допустимую позицию и дать продолжить движение, когда данные для столкновений готовы.

## Стадия разработки

Проект находится на раннем этапе. Подготовлены спецификации 1.7.10, инструменты проверки и результаты эталонных прогонов. Ближайшая цель — войти ванильным клиентом на собственный Rust-сервер, изменить блок и увидеть это изменение после перезапуска.
