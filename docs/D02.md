## Фактические прогоны D02

### S01 · SHA‑1 артефактов

Ручная сверка выполнена на Windows. Команда из PowerShell:

```powershell
$ref = Join-Path $env:USERPROFILE 'Documents\ferrite-reference'; @('versions\1.7.10\1.7.10.jar','server-vanilla\minecraft_server.1.7.10.jar','libraries\net\minecraftforge\forge\1.7.10-10.13.4.1614-1.7.10\forge-1.7.10-10.13.4.1614-1.7.10.jar') | ForEach-Object { $file = Join-Path $ref $_; if (Test-Path -LiteralPath $file -PathType Leaf) { '{0}  {1}' -f (Get-FileHash -LiteralPath $file -Algorithm SHA1).Hash, $_ } else { "MISSING  $_" } }
```

| Артефакт | Полученный SHA‑1 | Сверка с S01 |
|---|---|---|
| Клиент Java 1.7.10 | `E80D9B3BF5085002218D4BE59E668BAC718ABBC6` | PASS |
| Dedicated server Java 1.7.10 | `952438AC4E01B4D115C5FC38F891710C4941DF29` | PASS |
| Forge Universal 10.13.4.1614 | `25FD97F72BECA728112256938E03E8105B1B78CC` | PASS |

### Полный Python-набор

Windows, Python `3.14.7`, фактическая ревизия `3755fe1` (`engineering/D01-workspace`). Команда `git diff --name-status 3755fe1 5bd3e21 -- tests tools` не показала различий в этих каталогах между ревизией прогона и базой D02.

```powershell
py --version; py -B -m unittest discover -s tests -p 'test_*.py' -v; "TEST_EXIT=$LASTEXITCODE"
```

```text
Python 3.14.7
Ran 85 tests in 1.638s

OK (skipped=2)
TEST_EXIT=0
```

83 теста прошли, 2 пропущены. Оба пропуска относятся к `CryptoModelTests` в `tests/test_s04_crypto.py`:

- `test_encryption_boundary_and_stream_fragmentation`
- `test_rsa_response_short_lengths_and_token`

Причина из вывода — `Optional cryptography package unavailable; crypto model NOT tested`. Тесты вычисления хеша из того же модуля прошли.

## Исторические предложения Horizon

В [S02](contracts/blocks.md) внутреннее представление состояний Horizon и адаптер `modern_view` описывают старую архитектуру. Для Ferrite Worlds полезны наблюдаемые данные ID/meta, NBT и привязки реестра. Выбор внутреннего представления остаётся за задачами нового движка.

В [S10](specs/mod-api.md) форматы `.hnmod` и `.hmod`, порядок хуков и правила нативного API описывают предложения Horizon. Эталоном Java/Forge служат измерения на указанном стенде — загрузка, записи реестра, сохранение файла и наблюдаемый исход подключения. Вопросы порядка обработчиков, нативного API и формата расширений проверяются по текущим задачам Ferrite Worlds.

[Матрица S11](PARITY_MATRIX.md) хранит исходные статусы и ссылки старого плана. Действующие критерии Ferrite Worlds находятся в [бэклоге](../planning/backlog.json).
