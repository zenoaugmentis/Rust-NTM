# D01. Rust workspace и headless-сервер

Версия Rust — `1.99.1`. Она закреплена в корневом `rust-toolchain.toml`.
На Windows я проверил сборку с `x86_64-pc-windows-msvc`.

Из корня репозитория:

```text
cargo build --locked
cargo test --locked
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
```

Тест `creates_world_directory_and_stops_on_command` запускает сервер,
проверяет создание временного каталога мира и штатное завершение по `stop`.
